## **PikPak 到底是什麼？先搞清楚再說**

PikPak 是一個私密雲端硬碟，最大賣點是「雲端代抓」——你貼一個磁力連結或 BT 種子進去，它直接在伺服器端幫你抓好，然後放在你的雲盤裡。你不用在自己電腦跑 qBittorrent，不用開著電腦等，也不用擔心 ISP 看到你在跑 BT。

它還支援 4K 原畫質線上播放、Telegram Bot 整合、WebDAV 連線，可以說是很多人拿來取代傳統 NAS 或 PT 下載工具的方案。

目前 PikPak 支援多平台：Android、iOS、Windows、macOS、電視、網頁版通通都有。

## **Mac 版安裝注意事項**

Mac 安裝流程和 Windows 差不多，但要注意**先確認自己的 Mac 是哪種晶片**：

- 蘋果選單 → 關於這台 Mac → 查看「晶片」那一欄
- 有寫 Apple M1/M2/M3/M4 的就選 Apple Silicon 版
- 寫 Intel 的就選 Intel 版

下載錯版本的話軟體可能無法啟動，所以這個確認步驟別跳過。

## **常見問題 Q&A**

**Q：PikPak 電腦版支援 Windows 幾？**
A：官方主流支援 Windows 10 / 11，Windows 7 / 8 也有另外的安裝包可以下載，官網桌面版頁面有提供。

**Q：Mac M1/M2/M3/M4 可以用嗎？**
A：可以，下載 Apple Silicon 版本就行，Intel 版和 Apple Silicon 版是分開的兩個安裝檔，選錯了安裝可能會出問題。

**Q：台灣用戶算全球會員還是區域會員？**
A：台灣不在 PikPak 定義的「發達國家」名單內，所以通常會被歸為區域會員，享有較便宜的定價，下載速度最高 8 MB/s。

**Q：兌換碼可以在哪裡使用？**
A：Android App、桌面版客戶端、網頁版都可以使用兌換碼，在購買會員頁面右上角找「兌換碼」按鈕即可。**注意：iPhone / iPad 版無法直接使用兌換碼**，需要在其他平台操作。

**Q：會員到期後我的檔案還在嗎？**
A：會在，但帳戶會恢復免費版狀態。如果你的使用量超過 6 GB 配額，會進入「超額使用狀態」，影片在線播放會受限，下載速度降到 100 KB/s。有 6 個月的時間處理，不會立刻刪除。
